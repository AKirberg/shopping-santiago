---
name: Downtown galleries presentation
description: Compact, expandable presentation rules for the downtown galleries section.
---

Keep the downtown galleries section collapsed by default as a compact banner. Reveal the map, zone filters, gallery cards, and walking note only when the visitor expands it.

**Why:** The galleries are useful supporting content but should not dominate the main page length before a visitor expresses interest.

**How to apply:** Preserve the section anchor and make both expand and collapse actions clear in every supported language.
